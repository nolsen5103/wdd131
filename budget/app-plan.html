Overview

Purpose

The Budget Buddy personal budget planner helps users track income and expenses, organize spending by category, and see whether they are staying within their budget. The site can provide a simple visual summary of spending and alert users when they are close to and/or over their budget.

Audience

The target audience for this budget planner are individuals who generally want to learn financial responsibility or reduce unnecessary spending. I also want the tool to be helpful for college students who need to manage a limited income.

Dynamic elements

Some dynamic elements I will implement will include but are not limited to: Event listeners (such as button clicks), conditional branching (showing different messages based on remaining balance), objects (expenses stored as objects), and arrays (Storing expenses in an expenses array),

Pseudocode for your project

START Create an empty expenses array Select: income input budget input expense form expense list category filter total income display total expenses display remaining balance display budget message WHEN the user submits the income form: Get the income amount Store the income amount Update the summary WHEN the user submits the expense form: Get the expense name, amount, category, and date Create an expense object Add the object to the expenses array Display the updated expense list Recalculate total expenses Update the remaining balance To calculate total expenses: Add all expense amounts using reduce() To calculate remaining balance: Subtract total expenses from income IF remaining balance is greater than zero: Display "You are within your budget" ELSE IF remaining balance equals zero: Display "You have reached your budget" ELSE: Display "You are over budget" WHEN the user selects a category: Filter the expenses array by category Display only matching expenses WHEN the user clicks delete: Remove the selected expense from the expenses array Update the expense list and summary WHEN the user clicks reset: Clear the expenses array Clear the form fields Reset all totals END
